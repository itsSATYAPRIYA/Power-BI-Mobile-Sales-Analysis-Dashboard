# Power-BI-Mobile-Sales-Analysis-Dashboard
Interactive Power BI dashboard for mobile sales analysis, featuring KPI tracking, city-wise sales insights, product performance, customer ratings, payment trends, and brand comparison.
Mobile Sales Dashboard | Power BI
Overview

The Motorola Mobile Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI. The dashboard provides a comprehensive view of mobile sales performance by combining sales, customer, product, and transaction data into a single analytical report.

The objective of this project is to transform raw sales data into meaningful insights that can support business decisions, identify sales trends, and evaluate customer purchasing behavior.

Key Features
Interactive month-wise filtering
KPI cards for quick business performance monitoring
City-wise sales visualization using maps
Daily and monthly sales trend analysis
Mobile model performance comparison
Payment method distribution analysis
Customer rating insights
Day-wise sales performance tracking
Brand-wise sales and quantity comparison

Insights Generated
Sales performance can be monitored across different months using interactive filters.
Geographic analysis highlights sales distribution across major Indian cities.
Product-wise analysis helps identify the highest-performing mobile models.
Customer ratings provide an overview of customer satisfaction levels.
Payment method analysis reveals customer transaction preferences.
Brand comparison enables evaluation of market performance among leading smartphone brands.
Day-wise sales trends help identify peak business days.
